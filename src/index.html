GAME UPDATE FREEZE

Steam installs only: sets the game to "update only on launch" and locks the Steam manifest so no update can be scheduled; the Launch button then starts the game directly. Turn it off before playing online modes that need the current build — launching from the Steam UI itself can still force an update. EA App users: disable automatic game updates in the EA App's own settings.

Two UE4SS mods (ZCSDKBridge + ZCSDKLoader) bundled with Mod Command — nothing to download. Requires UE4SS; installed mods that need it show a ◆ SDK chip in the Hangar.
