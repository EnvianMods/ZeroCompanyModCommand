GAME UPDATE FREEZE

Steam installs only: sets the game to "update only on launch" and locks the Steam manifest so Steam cannot apply an update. While it is on, play with DIRECT LAUNCH (starts the local exe, no update check). LAUNCH GAME always goes through Steam, update check included: press it, or Play in Steam, while a game update is pending and Steam shows "An error occurred while launching this game: Disk write error – appmanifest_2075800.acf". That is the freeze blocking the update, not damage to your install: turn the freeze off here to let Steam update, or keep using DIRECT LAUNCH to stay on your current build. Online modes may need the current build. EA App users: disable automatic game updates in the EA App's own settings.

Content-mod runtime (needed by mods built with the Zero Company Mod SDK — new items, gear, and other added content) —

Two UE4SS mods (ZCSDKBridge + ZCSDKLoader). Mod Command checks the ZCSDK-Runtime-Release GitHub repo at startup and installs the newest release from there, so runtime updates no longer wait for a Mod Command update; a bundled copy covers offline installs. At startup the runtime loads each SDK-built mod's asset registry so the game can discover its new content, and grants the mod's items once per save. Requires UE4SS; installed mods that need it show a ◆ SDK chip in the Hangar.

WHAT THE SDK IS

Mod Command installs and manages mods. The Zero Company Mod SDK is the other half: the toolkit that makes them. It scaffolds a mod from one of 30-plus recipes (a new item, a weapon, an ability, a cost or balance change, a whole character class), checks it against the game's own reflected data before you build, cooks it through Unreal, and deploys it into the game — each step a button, with the real build log in front of you. It is a separate download on its own release cadence. Install it, point Mod Command at it here, and this view becomes the SDK's own workbench inside this window. The workbench walks you through it: a guided first mod, a build stepper that explains failures, an editor for your mod's definition, an asset drop zone, and test / conflicts / publish pages — all inside this Forge view.
